# STYLE FORGE 비주얼 편집기 v1.2

1. Chrome에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 폴더( manifest.json이 있는 폴더)를 선택합니다.
4. 쇼핑몰을 열고 확장 프로그램 메뉴에서 STYLE FORGE를 클릭합니다. 자주 사용하면 고정하세요.
5. 화면의 글씨·버튼·영역을 클릭하여 편집합니다. 상위 요소 버튼으로 컨테이너를 선택할 수 있습니다.
6. 기본은 선택한 요소만 수정합니다. 같은 class의 요소 범위는 대상 개수를 확인하고 선택하세요.
7. 스킨 분석기의 비주얼 연결 JSON을 연결하면 관련 파일 경로·줄 후보가 표시됩니다.
8. 원본 비교 / 실행 취소 / 다시 실행 / 변경사항 검토 후 CSS를 복사·다운로드합니다.
9. 편집 저장은 Chrome 로컬 저장소에 페이지별로 저장합니다. 재접속 후 확장을 열고 저장 불러오기를 누르세요.
10. 닫기는 임시 변경을 제거합니다. 새로고침이나 페이지 이동도 적용을 해제합니다. 서버·FTP 파일은 변경하지 않습니다.

외부 CSS 시트는 CORS로 규칙을 읽지 못할 수 있지만 계산된 CSS와 편집은 가능합니다. iframe 내부·Shadow DOM 내부·브라우저 제한 페이지는 현재 직접 편집하지 않습니다. 위치 기반 선택자는 실제 구조가 바뀌면 재검토하세요. 인라인 !important가 있는 경우 생성된 CSS만으로 적용되지 않을 수 있습니다. CSS는 기존 선언을 자동 수정하는 대신 별도 override 파일로 적용합니다. 운영 적용 전에 원본 백업과 페이지별 확인을 수행하세요.
