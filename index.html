    사용 순서와 실제 반영
    1. 담당자가 협업 서버를 설치하고 클라이언트 계정과 쇼핑몰 프로젝트를 만듭니다.
    2. 클라이언트는 비주얼 편집기에서 수정 후 검토 요청을 보냅니다.
    3. 담당자는 페이지 목록과 전후 값을 확인하고 ‘홈페이지 표시 JSON’을 편집기에 불러와 변경 영역을 봅니다.
    4. 승인된 항목만 적용 패키지로 다운로드합니다.
    5. Mac 적용 프로그램에서 패키지·대상 스킨·파일 차이를 검토한 뒤 적용합니다. 원본 백업과 해시 충돌 검사를 수행합니다.

    카페24 쇼핑몰 HTML 스킨에 협업 저장 서버를 설치할 수는 없습니다. 실제 온라인 제출에는 별도 Node.js 협업 서버와 HTTPS 주소가 필요합니다. 로컬 체험의 승인은 운영 반영용 서명이 아닙니다.
