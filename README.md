# STYLE FORGE v1.0

프레임워크와 빌드 도구 없이 실행되는 한국어 디자인 시스템 생성기입니다.

## 실행

```sh
cd /workspace/style-forge
python3 -m http.server 8000 --bind 0.0.0.0
```

브라우저에서 서버의 8000 포트로 접속합니다. `index.html`, `style.css`, `app.js`를 같은 폴더에 배포하면 일반 정적 웹 호스팅에서도 실행됩니다. 클립보드 API는 HTTPS 또는 localhost에서 동작하며, 그 외 환경에서는 브라우저의 복사 기능을 시도합니다.

## 기능

- 브랜드·텍스트·배경 색상, 자동 팔레트, 타이포그래피와 공간 토큰
- 버튼 크기·모서리·호버, 카드 모서리·그림자·테두리
- 실시간 컴포넌트 미리보기와 모바일 폭 전환
- 전체 CSS / 토큰 / 컴포넌트 보기 및 선택 탭 복사
- 전체 CSS 다운로드, 프로젝트 이름 기반 파일명
- LocalStorage 프로젝트 저장·불러오기·삭제

프로젝트는 현재 브라우저와 접속 주소에 저장되며 다른 기기와 동기화되지 않습니다. 이름이 같은 프로젝트를 저장하면 기존 프로젝트를 갱신합니다. 브라우저 재접속 시 저장 목록에서 선택하여 불러오세요. 초기화는 현재 토큰만 기본값으로 되돌립니다.

미리보기 버튼은 클릭 상태를 확인하는 데모이고, 이메일 폼은 브라우저 입력 검증을 시연합니다. 외부 요청이나 이메일 전송은 하지 않습니다.

## 구조와 확장

- `index.html`: 시맨틱 화면 구조와 한국어 인터페이스
- `style.css`: 관리자 도구 화면, 반응형 레이아웃
- `app.js`: 토큰 기본값·검증, CSS 생성, 미리보기, 저장과 내보내기

새 토큰은 `DEFAULTS`, 해당 설정 컨트롤, `generateCSS`에 추가합니다. CSS 생성은 미리보기와 내보내기에서 공유하므로 동일하게 반영됩니다. 프로젝트 데이터에는 v1 전용 저장 키를 사용합니다. 이후 컴포넌트 확장, JSON 가져오기/내보내기, 프로젝트 동기화를 단계적으로 추가할 수 있습니다.

## 검증

Chromium에서 색상·타이포그래피·버튼·카드 설정, 저장 후 페이지 재접속과 불러오기, 삭제, CSS 탭 전환·클립보드 복사·다운로드 내용, 폼 검증, 초기화, 390px 모바일 가로 넘침을 확인했습니다. JavaScript 문법 검사와 브라우저 오류 검사도 통과했습니다.
