# v1.1 분석기 구조

## 기능과 데이터 흐름

```
폴더 / ZIP / TAR.GZ
  → archive.js: 경로 검증, 크기 제한, 압축 읽기, 텍스트 디코딩
  → engine.js: parse5 HTML + CSS Tree CSS + Acorn JS 구문 트리
  → 파일·토큰·선택자·참조·이벤트·근거와 경고
  → ui.js: 탐색 / 검색 / 소스 미리보기 / JSON 내보내기
```

- `app.js`는 v1.0 생성기를 그대로 담당한다.
- `analyzer/archive.js`는 사용자 File 객체를 읽는다. 디스크에 압축을 풀지 않는다. UTF-8 실패 시 EUC-KR을 추정하며 경고를 표시한다. TAR 경로·크기·헤더 체크섬, ZIP 종료·디렉터리 구조와 크기를 검증한다. 링크를 따라가지 않는다.
- `analyzer/engine.js`는 브라우저 DOM이나 스킨 스크립트를 실행하지 않는다. parse5의 소스 위치를 사용해 HTML 속성·module·inline CSS/JS의 줄을 기록한다. CSS 구문 트리로 선택자 목록·선언·!important·중복·명시도·미디어/지원 조건을 추출한다. JS 구문 트리에서 jQuery/DOM 쿼리·정적 이벤트·위임·Swiper·클래스 변경을 기록한다. 구문 분석 실패 시 문자열 후보로 대체하고 추정으로 표시한다.
- `analyzer/worker.js`가 로딩·분석을 별도 스레드에서 실행한다. 진행 상태·결과·오류만 UI에 전달하며 취소 시 Worker를 종료한다.
- `analyzer/style.css`는 새로운 탭과 분석 화면의 미니멀 화이트 반응형 스타일을 담당한다. 기존 v1.0 CSS는 유지한다.
- `analyzer/ui.js`는 textContent로 소스를 출력한다. HTML을 렌더링하지 않는다. 검색 결과는 100개씩 추가하며 CSS 연결은 선택자당 최대 200개, JS 이름 후보는 50개까지 저장한다. class/id 목록은 처음 150개와 검색을 제공한다. 소스는 이동 줄 주변 101줄을 표시하고 전체 텍스트 다운로드를 제공한다.
- `vendor/analyzer-worker.js`는 오프라인 런타임용 번들이다. 파서/압축 라이브러리의 버전과 라이선스는 lockfile과 `vendor/LICENSES.txt`에 고정한다. `npm run build`로 갱신한다.

## 연결과 확신 수준

- **정적 속성**: 파일에 class/id 속성이 실제로 존재한다.
- **정적 구조 일치**: 지원되는 선택자(태그/class/id/속성/자식·자손·형제 조합)가 한 HTML 파일의 파싱된 구조와 일치한다. 카페24 모듈 실행이나 실제 적용 CSS의 판정이 아니다.
- **이름 후보·미확인**: 토큰 이름은 존재하지만 구조가 다르거나 의사클래스·동적 상태·import 조합·템플릿 처리 때문에 확정할 수 없다.
- **정적 문자열 / 실행 미확인**: JS에 리터럴 선택자나 이벤트 등록 코드가 있다. 코드가 실행되거나 해당 대상에 도달했다고 주장하지 않는다. 변수·문자열 결합을 평가하지 않는다.
- **파일 확인**: import/파일 참조 경로가 선택한 소스 집합 안에 존재한다. 외부/동적 경로는 요청하지 않는다. 루트 경로는 현재 파일의 상위 폴더부터 후보를 찾고 여러 후보를 전부 표시한다.

CSS의 `context`는 media/supports/layer 등 조건 문맥이다. 명시도 수치는 일반 선택자 및 :is/:not/:has/:where의 참고값이며 특수 의사클래스와 CSS nesting에는 제한이 있다. **분석 순서**는 파일 정렬 후 발견 순서이고 실제 stylesheet 로드 순서가 아니다. !important도 선언 정보일 뿐 최종 우승 선언을 계산하지 않는다. 미디어 조건·캐스케이드 계층·페이지 로드 순서·런타임 DOM이 없는 상태에서 현재 적용 CSS를 단정하지 않는다.

모듈명은 일반 속성처럼 실행하지 않고 카페24 메타데이터로 유지한다. `@import/@layout/@css/@js`와 CSS `@import`, stylesheet/script 참조는 연결만 제공한다. import를 재귀 렌더링하거나 카페24 변수와 모듈을 확장하지 않으므로 순환 import도 실행되지 않는다.

## 후속 확장

v1.2의 MV3 확장 프로그램이 실제 DOM·computed styles·페이지 URL을 제공하면 v1.1 파일/선택자 인덱스와 연결하는 어댑터를 추가한다. v1.3에서 PC/모바일 루트 매핑과 수정 diff를 추가한다. 원본 스킨 쓰기·자동 FTP·운영 서버 수정은 현재 기능에 포함하지 않는다.
